# Travel Fieldnotes — From prompt to guide

This product demonstration uses reconstructed public examples. It includes no personal itinerary, source report, booking reference or traveller identity. Prices and accommodation attributes are illustrative; no live quotes, ratings or availability are claimed. Airbnb is named only as a category of accommodation research; no endorsement or affiliation is implied.
